Vamos criar um sistema de mensagens que demonstra tanto métodos padrão quanto métodos estáticos em interfaces. Você criará uma interface com funcionalidade integrada que as classes que a implementarem poderão usar diretamente ou personalizar conforme necessário.

Você organizará seu código em quatro arquivos:

Messenger.java: Defina uma interface que represente qualquer serviço de mensagens. Ela deve declarar um método abstrato sendMessage(String message) que retorna void. Adicione um método padrão chamado sendWithTimestamp(String message) que imprima: [TIMESTAMP] seguido da chamada de sendMessage(message). Inclua também um método estático chamado formatMessage(String message) que retorne a mensagem convertida para letras maiúsculas.
EmailMessenger.java: Crie uma classe que implemente Messenger. Ela terá um campo recipient (String). Inclua um construtor para inicializar o destinatário. Implemente sendMessage() para imprimir: Email to [recipient]: [message]. Essa classe usa o método padrão sendWithTimestamp() como está.
SMSMessenger.java: Crie outra classe que implemente Messenger. Ela terá um campo phoneNumber (String). Inclua um construtor para inicializar o número de telefone. Implemente sendMessage() para imprimir: SMS to [phoneNumber]: [message]. Substitua o método padrão sendWithTimestamp() para imprimir: [URGENT] seguido da chamada de sendMessage(message), em vez de usar o comportamento padrão de registro de data e hora.
Main.java: Reúna tudo para demonstrar os métodos padrão e estático de interfaces. Você receberá três entradas: um destinatário de e-mail, um número de telefone e uma mensagem. Primeiro, use o método estático Messenger.formatMessage() para formatar a mensagem e armazená-la. Em seguida, crie um EmailMessenger e um SMSMessenger. Para cada mensageiro, chame sendWithTimestamp() com a mensagem formatada: observe como o EmailMessenger usa a implementação padrão, enquanto o SMSMessenger usa sua versão substituída.
Você receberá três entradas: o destinatário do e-mail (String), o número de telefone (String) e a mensagem (String).

Sua saída deve mostrar quatro linhas ao todo: duas para cada mensageiro: uma linha de prefixo ([TIMESTAMP] ou [URGENT]) seguida pela linha da mensagem. O EmailMessenger mostrará o prefixo de registro de data e hora padrão, enquanto o SMSMessenger mostrará seu prefixo urgente personalizado. Ambos usarão a mensagem formatada estaticamente (em letras maiúsculas)!
