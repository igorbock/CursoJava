Construa uma classe Calculator completa que utilize todos os conceitos aprendidos:

Campos: Campos privados para name (String), memory (double), operationCount (int)
Construtores: Um construtor parametrizado e um construtor padrão usando encadeamento com this()
Palavra-chave this: Use this para atribuir campos e acessá-los nos métodos
Getters: getName(), getMemory(), getOperationCount()
Métodos: add, subtract, multiply, divide, power
O método add armazena seu resultado em memory. Todos os métodos incrementam operationCount. O método divide retorna 0 se houver divisão por zero. O método power utiliza Math.pow().
